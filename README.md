## One laboratory, complementary marks

The **colorful Geometric Impossible Duck is primary**. The technical PA duck is a complementary research mark with a complete hidden Ochre A/P relationship and Ochre beak. Both round and rectangular Lab Stamps, the PF monogram, construction studies and aged impressions remain part of the same family. `EST. 2025` belongs in secondary institutional treatments, never inside the primary geometric mark.

Project identity follows **different experiments, one laboratory**: fixed typography, palette rules, layout and small colorful lab attribution; controlled project name, category, descriptor, accent, optional identifier and relevant study motif. Projects remain Patitos Fortune experiments, not independent sub-brands. The current generator exports 1280 × 640 SVG/PNG cards; the broader identity principle also guides future documentation and website applications. The four shipped examples are fictional and are not upload-ready identities for real repositories.

```text
brand/source/       Canonical duck masters; generated clean stamps and PF
brand/palette/      Exact tokens, roles and contrast restrictions
brand/stamps/       Restrained Ochre-detail clean stamp derivatives
brand/avatars/      Six approved SVG + 512 px PNG treatments
brand/derived/      Aged impressions and construction presentations
brand/social/       Project-identity template, inputs and fictional examples
brand/tools/        Existing deterministic builders, renderers and validators
brand/review/       Approval/protection manifests, final integrity manifest
profile/            Approved organization README and responsive headers
```
